# Derive Validation evidence from canonical geometry

VenueMind treats serialized Room Boundaries, Footprints, inventory counts, Route Graphs, and sightline samples as the source of Validation evidence; stored summary metrics are compatibility outputs rather than proof. This costs more computation than trusting precomputed values, but it makes Proposal results reproducible, ties every outcome to stable object IDs and geometry fingerprints, and ensures Approval commits the same spatial Changes that were validated.
